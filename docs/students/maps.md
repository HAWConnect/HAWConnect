# Campus map / Campuskarte

## English

Open Map and search for a campus, address or building label such as **BT7**. Select a building or search result to view its available details. Campus entries offer directions and links to the official campus plan and location information. The map covers Berliner Tor, Bergedorf, Finkenau and Armgartstraße.

Map tiles need a network connection. You can deny location permission and still browse the campuses; location is optional for the location control. Directions open your external maps application. Indoor floor navigation and live room availability are not provided. Consult [HAW locations](https://www.haw-hamburg.de/en/university/locations/) for official information. Map data includes OpenStreetMap; keep the displayed attribution when sharing screenshots.

## Deutsch

Öffne die Karte und suche nach einem Campus, einer Adresse oder einer Gebäudebezeichnung wie **BT7**. Wähle ein Gebäude oder Suchergebnis für die verfügbaren Details. Campuseinträge bieten Routenlinks sowie offizielle Lagepläne und Standortinformationen. Die Karte umfasst Berliner Tor, Bergedorf, Finkenau und Armgartstraße.

Kartenkacheln benötigen eine Verbindung. Auch ohne Standortfreigabe kannst du die Campusse ansehen; die Standortfunktion ist optional. Routen werden in einer externen Karten-App geöffnet. Indoor-Etagennavigation und eine Live-Raumbelegung werden nicht angeboten. Offizielle Angaben findest du unter [HAW-Standorte](https://www.haw-hamburg.de/hochschule/standorte/). Die Karte verwendet unter anderem OpenStreetMap; Quellenhinweise sollen beim Teilen von Screenshots erhalten bleiben.
