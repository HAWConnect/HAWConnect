# Calendar imports / Kalender importieren

## English

1. Open Calendar, then its Settings and **Import / manage calendars**.
2. Choose an `.ics` file you already obtained from myHAW, or paste a calendar export link if your myHAW setup provides one. Do not enter your university password.
3. Preview the events, then confirm the import. Repeat for a separate calendar if needed.
4. Use the management screen to replace, refresh or remove an imported calendar.

File imports are snapshots: import an updated file to get changes. Linked calendars refresh on app opening/foreground and periodically while running, subject to the refresh interval and network availability; manual refresh is also available. A cancellation appears only after a successful refresh and if the source reflects it. This is not a push-notification or guaranteed background-refresh service.

If a link fails or requires an authenticated browser session, try a downloaded `.ics` file. Existing events are retained after a failed refresh. Treat export links as private: they can contain access tokens. Public **Semester Dates** are separate from your personal classes; check the official HAW information for binding dates.

## Deutsch

1. Öffne den Kalender, danach dessen Einstellungen und **Kalender importieren / verwalten**.
2. Wähle eine bereits aus myHAW bezogene `.ics`-Datei oder füge einen Kalender-Exportlink ein, sofern dein myHAW-Angebot diesen bereitstellt. Gib kein Hochschulpasswort ein.
3. Prüfe die Vorschau und bestätige den Import. Weitere Kalender kannst du getrennt hinzufügen.
4. Über die Verwaltung kannst du einen importierten Kalender ersetzen, aktualisieren oder entfernen.

Dateiimporte sind Momentaufnahmen. Für Änderungen musst du eine aktualisierte Datei importieren. Verknüpfte Kalender werden beim Öffnen, bei der Rückkehr in die App und während der Nutzung regelmäßig aktualisiert, abhängig von Aktualisierungsintervall und Verbindung. Eine manuelle Aktualisierung ist ebenfalls möglich. Ein Ausfall wird erst sichtbar, wenn die Quelle ihn enthält und die Aktualisierung erfolgreich war. Es gibt keine garantierte Hintergrundaktualisierung oder Push-Benachrichtigung.

Wenn ein Link nicht funktioniert oder eine angemeldete Browsersitzung erfordert, nutze eine heruntergeladene `.ics`-Datei. Bei einer fehlgeschlagenen Aktualisierung bleiben vorhandene Termine erhalten. Exportlinks können Zugriffstoken enthalten und sollten vertraulich bleiben. Öffentliche **Semesterzeiten** sind von deinen Lehrveranstaltungen getrennt; verbindliche Angaben findest du bei der HAW.
