Retrieved 23 October 2026 using four bounded read-only OSM map API requests covering Berliner Tor, Bergedorf, Finkenau and Armgartstraße. Each feature retains its source way URL and retrieval date. Selected building addresses were matched to HAW's published campus locations and the 2026 Berliner Tor campus plan. This collection contains 20 building footprints; it is not a complete inventory of university property. Adjacent unrelated institutions were excluded.

Update geometry using its source IDs, verify addresses against official HAW campus information, retain this notice and preserve ODbL obligations when distributing modified data. Application source licensing does not replace the data licence.

The additional AL1, JU10 and AS24 polygons were retrieved with three rate-limited Nominatim address queries. Source way IDs are retained per feature. Facility listings and building codes come from the official HAW campus PDFs, linked in haw-campuses.ts; ODbL attribution applies to geometry.
